# Healthcare dbt Analytics

A hands-on healthcare analytics data warehouse project built with dbt, SQL, BigQuery, GitHub, and Power BI.

## Project goals

- Learn dbt fundamentals through a realistic data-engineering project
- Build staging, intermediate, and analytics-ready models
- Implement automated data-quality tests
- Practice dbt sources, refs, Jinja, macros, snapshots, and incremental models
- Use Git/GitHub for version control and CI/CD

## Planned architecture

Raw healthcare data → BigQuery → dbt staging → intermediate → marts → BI

## Data domains

- Patients
- Providers
- Claims
- Encounters
